# 🖥️ System Monitor - Приложение для мониторинга системы

Полнофункциональное приложение для мониторинга всех показателей системы в реальном времени.

## 📁 Структура проекта

```
/workspace/
├── core.py          # Ядро мониторинга (сбор всех метрик)
├── gui.py           # Графический интерфейс (tkinter)
├── builder.py       # Сборщик EXE с интерактивным меню
└── README.md        # Этот файл
```

## 🔧 Требования

- Python 3.8+
- psutil (для сбора системных метрик)
- pyinstaller (для сборки EXE, опционально)
- tkinter (для GUI, обычно встроен в Python)

## 🚀 Быстрый старт

### Запуск ядра (консольный режим)
```bash
python core.py
```

### Запуск GUI версии
```bash
python gui.py
```

### Запуск сборщика EXE
```bash
python builder.py
```

## 📋 Возможности ядра (core.py)

Ядро собирает следующие показатели:

### CPU
- Процент загрузки (общий и по ядрам)
- Количество физических и логических ядер
- Текущая и максимальная частота
- Load Average (для Unix)
- Переключения контекста и прерывания

### Память
- Общий объем RAM
- Использовано/Доступно
- Процент использования
- Swap память

### Диск
- Информация о разделах
- Использование места
- Операции чтения/записи
- I/O статистика

### Сеть
- Отправленные/полученные байты
- Пакеты, ошибки, дропы
- Активные соединения
- Локальный IP адрес

### Процессы
- Общее количество процессов
- Top процессы по CPU и RAM
- Детальная информация о каждом процессе

### GPU (если доступен)
- Название видеокарты
- Загрузка GPU
- Использование памяти
- Температура

### Батарея (для ноутбуков)
- Процент заряда
- Статус подключения
- Оставшееся время работы

### Температура
- Датчики температуры системы
- Критические пороги

## 🎨 Графический интерфейс (gui.py)

GUI предоставляет:
- Красивый темный интерфейс
- Карточки с метриками
- Прогресс-бары для наглядности
- Лог событий в реальном времени
- Возможность сохранения отчета в JSON
- Цветовая индикация (зеленый/желтый/красный)

## 🔨 Сборка EXE (builder.py)

Сборщик предоставляет интерактивное меню:

```
======================================================================
🖥️  System Monitor - Сборщик EXE (Улучшенная версия)
======================================================================

Выберите действие:
  1. Установить зависимости и собрать EXE
  2. Только собрать EXE (зависимости уже установлены)
  3. Собрать консольную версию (для отладки ошибок)
  4. Очистить временные файлы
  5. 🧪 Тестировать приложение перед сборкой
  6. Выйти
```

### Особенности сборщика:

1. **Автоматическая установка зависимостей** - psutil и pyinstaller
2. **Тестирование перед сборкой**:
   - Проверка наличия всех файлов
   - Проверка целостности кода
   - Тестирование ядра
   - Проверка импортов GUI
3. **Обработка ошибок** - терминал остается открытым при ошибках
4. **Очистка** - удаление временных файлов сборки

## 💡 Примеры использования

### Использование ядра в своем коде

```python
from core import SystemMonitorCore

core = SystemMonitorCore()

# Получить снимок системы
snapshot = core.get_snapshot()

print(f"CPU: {snapshot.cpu.usage_percent}%")
print(f"RAM: {snapshot.memory.percent}%")
print(f"Процессов: {snapshot.processes.total_processes}")

# Или получить JSON
json_report = core.to_json()
print(json_report)

# Запустить фоновый мониторинг
def on_update(snapshot):
    print(f"Update: CPU={snapshot.cpu.usage_percent}%")

core.add_callback(on_update)
core.start_monitoring(interval=1.0)
```

## ⚠️ Примечания

1. **GPU мониторинг** требует установки дополнительных библиотек:
   - `pip install py3nvml` или `pip install pynvml` (для NVIDIA)

2. **GUI версия** требует графической среды (X11/Wayland на Linux)

3. **Некоторые метрики** могут быть недоступны в контейнерах или на серверах

## 🛠️ Решение проблем

### Ошибка "tkinter not found"
```bash
# Ubuntu/Debian
sudo apt-get install python3-tk

# Windows/Mac - обычно установлен по умолчанию
```

### Ошибка при сборке EXE
1. Убедитесь, что все зависимости установлены
2. Используйте опцию 3 (консольная версия) для отладки
3. Проверьте логи сборки

### Нет данных о температуре/батарее
Это нормально для:
- Серверов без датчиков
- Контейнеров Docker
- Виртуальных машин
