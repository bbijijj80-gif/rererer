# 🖥️ System Monitor - Мониторинг Системы

Приложение для мониторинга системы с **реальным ядром** на Python, которое получает настоящие данные о вашем компьютере.

## 📁 Структура проекта

```
/workspace/
├── core.py          # Реальное ядро системы мониторинга
├── app.py           # Графическое приложение (Tkinter)
├── build.py         # Скрипт для сборки в EXE
└── README.md        # Этот файл
```

## 🔧 Требования

- Python 3.6+
- Библиотеки:
  - `psutil` - получение системной информации
  - `tkinter` - графический интерфейс (встроен в Python)
  - `pyinstaller` - сборка в EXE (опционально)

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install psutil pyinstaller
```

### 2. Запуск приложения

```bash
python app.py
```

Или протестировать ядро отдельно:

```bash
python core.py
```

### 3. Сборка в EXE файл

```bash
python build.py
```

Выберите опцию **1** или **2** в меню для создания EXE файла.

Готовый файл будет в папке `dist/SystemMonitor.exe`

## 📊 Возможности приложения

### Ядро (`core.py`)
- ✅ **Мониторинг CPU**: загрузка по ядрам, частота, количество ядер
- ✅ **Мониторинг RAM**: использование памяти, swap
- ✅ **Мониторинг дисков**: место на всех разделах
- ✅ **Мониторинг сети**: трафик, интерфейсы
- ✅ **Список процессов**: топ процессов по потреблению памяти
- ✅ **Системная информация**: OS, версия, время работы
- ✅ **Фоновый режим**: обновление данных в реальном времени
- ✅ **Callback система**: уведомления об изменениях

### Приложение (`app.py`)
- 🎨 Современный графический интерфейс
- 📈 Прогресс-бары с цветовой индикацией
- 🔄 Автоматическое обновление данных
- 📋 Таблица процессов
- 🖱️ Прокрутка для больших экранов
- ⏹️ Контроль мониторинга (старт/стоп)

## 💡 Пример использования ядра

```python
from core import SystemCore

# Создание экземпляра ядра
core = SystemCore()

# Получение всех данных
data = core.get_all_data()

print(f"CPU: {data['cpu']['usage_percent']}%")
print(f"RAM: {data['memory']['percent']}%")
print(f"Система: {data['system']['system']}")

# Или запустить фоновый мониторинг
def on_update(data):
    print(f"Обновление: CPU={data['cpu']['usage_percent']}%")

core.register_callback(on_update)
core.start(interval=1.0)  # Обновление каждую секунду
```

## 🛠️ Сборка EXE

### Команды PyInstaller вручную:

**Для Windows:**
```bash
pyinstaller --onefile --windowed --name SystemMonitor --add-data "core.py;." app.py
```

**Для Linux/Mac:**
```bash
pyinstaller --onefile --windowed --name SystemMonitor --add-data "core.py:." app.py
```

### Параметры:
- `--onefile` - один исполняемый файл
- `--windowed` - без консольного окна (для GUI)
- `--name` - имя приложения
- `--add-data` - включение дополнительных файлов
